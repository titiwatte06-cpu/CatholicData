✨ Key Features (ฟีเจอร์เด็ดที่มี)
🗺️ Interactive Church Map: แผนที่พิกัดวัดคาทอลิกทั่วไทย จัดกลุ่มตามสังฆมณฑล ค้นหาง่าย คลิกดูรายละเอียดได้ทันที

📅 Mass Schedules & Sermons: เช็คตารางมิสซาและอ่านบทเทศน์ประจำวันแบบอัปเดต

📰 News & Activities: เกาะติดข่าวสารและกิจกรรมเด่นจากชุมชนคาทอลิก

🛠️ Admin Dashboard: หน้าจัดการหลังบ้าน สำหรับมอนิเตอร์และเช็คสถานะความครบถ้วนของข้อมูลวัด

🌐 Bilingual Support: รองรับการใช้งานทั้งภาษาไทยและภาษาอังกฤษ (EN)

💻 Tech Stack (เครื่องมือทำมาหากิน)
Frontend: HTML, CSS, JavaScript / Modern Frontend Framework & Tailwind CSS

Backend: Node.js / Server-side architecture & REST APIs

Deployment & Hosting: Vercel 🚀
